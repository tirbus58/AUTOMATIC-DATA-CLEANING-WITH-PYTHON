# AUTOMATIC-DATA-CLEANING-WITH-PYTHON
Python script to automate CSV file cleaning and merging
Why is this script useful for data entry? 
Time saving: Instead of manually cleaning each file in Excel, everything is done automatically. 
Reliability: Avoids human errors (e.g., forgetting a duplicate). 
Scalability: Can process dozens of files in a single run. 
Relevance: Cleaning and merging tasks are common in data entry jobs and prepare for roles like data analyst.
